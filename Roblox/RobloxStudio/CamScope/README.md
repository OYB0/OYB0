# 📷 OYB CamScope Pro - Roblox Studio Plugin

An advanced camera management and real-time viewport visualization plugin for Roblox Studio developers.

## ✨ Features
* 🎥 **3D Camera Gizmo:** Live frustum visualization showing dynamic FOV and aspect ratio.
* 📷 **Real-Time Viewport Preview:** Preview world rendering in a floating dockable widget.
* 🔄 **Live Workspace Sync:** Instant synchronization with active camera selection.
* 🌐 **Multi-Language Support:** Localized in 7 languages (English, Arabic, Spanish, etc.).
