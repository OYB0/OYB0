# 📷 OYB CamScope Pro - Roblox Studio Plugin

Welcome to **CamScope Pro**! An advanced, multi-language Roblox Studio plugin designed to give developers total control over camera management, real-time viewport previewing, and 3D camera gizmo synchronization.

## 🛠️ Installation & Setup Guide

Follow these steps to install and start using the CamScope Pro plugin in Roblox Studio:

### 1. Plugin Installation ⚙️
* Go to the [CamScope Pro Roblox Page](https://create.roblox.com/store/asset/84925617114221).
* Click **"Get"** / **"Add to Inventory"** to add the plugin to your Roblox account.
* Open **Roblox Studio**, go to the **Plugins** tab, open **Toolbox**, switch to **Inventory** -> **Plugins**, and click **Install**.

### 2. Selecting a Camera 🎯
* Open the **CamScope Pro** main widget from the Studio **Plugins** tab.
* In the **Explorer** window, select any `Camera` instance.
* Click the **"🎯 Select Camera from Explorer"** button in the CamScope interface to bind it.

### 3. Real-Time Viewport Preview 📷
* Once a camera is selected, the **CamScope Preview** floating window will automatically launch.
* The preview window renders world geometry in real time.
* Click the **⚙️ Settings** icon in the preview window to toggle viewport filters for Parts, Models/NPCs, or Auto-Refresh mode.

### 4. Studio Camera Synchronization 🎥
* Click the **🎥 Sync Button** next to the camera selection button to snap your Studio view to the selected camera.
* When Studio Camera Sync is active, the 3D camera model automatically hides to prevent viewport obstruction.

## ⚙️ Key Features & Requirements

* 🌐 **Multi-Language Support:** Native localization for English, Arabic, Spanish, Portuguese, Russian, Korean, and Japanese.
* 🎥 **3D Camera Gizmo:** Automatically generates a detailed camera model with dynamic visual frustum lines showing FOV and aspect ratio bounds.
* 🔄 **Live Workspace Syncing:** Listens to workspace modifications and updates the viewport frame instantly.
* 🛠️ **No External Dependencies:** Works out of the box using built-in Roblox Studio API services (`RunService`, `Selection`, `DockWidgetPluginGui`).
